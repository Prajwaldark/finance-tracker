# 💰 Finance Tracker - Personal Debt & Loan Management

A beautiful, responsive web application to track your personal finances, manage loans you owe, and monitor money owed to you. Built with modern web technologies and featuring an AI-powered repayment strategy generator.

![Finance Tracker](https://img.shields.io/badge/Status-Production%20Ready-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)
![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20CSS%20%7C%20JavaScript%20%7C%20Tailwind-brightgreen)

## ✨ Features

- **📊 Dashboard Overview**: Real-time summary of your financial position
- **💳 Loan Management**: Track loans you owe with interest rates and EMIs
- **💰 Debt Tracking**: Monitor money owed to you by others
- **🤖 AI Strategy Generator**: Get personalized repayment recommendations
- **📱 Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **🌙 Dark/Light Mode**: Automatic theme switching with system preference
- **📅 Payment Reminders**: Track upcoming payments and overdue amounts
- **📤 Data Export**: Export your financial data in CSV or PDF formats
- **💾 Local Storage**: Your data stays private and local to your device

## 🎯 How It Works

1. **Add Loans**: Track money you owe with lender details, interest rates, and EMIs
2. **Add Debts**: Record money owed to you by others
3. **Monitor**: View your net financial position and upcoming payments
4. **Strategize**: Use AI-powered recommendations to optimize repayment
5. **Export**: Download your financial data for record-keeping

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - runs entirely in the browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/finance-tracker.git
   cd finance-tracker
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve .
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Start tracking your finances!**

## 📖 Usage Guide

### Adding a Loan
1. Click "Add Loan I Owe" button
2. Fill in lender details, amount, interest rate, EMI, and due date
3. Add optional notes
4. Click "Save Loan"

### Adding Money Owed to You
1. Click "Add Money Owed to Me" button
2. Enter debtor name, amount, and due date
3. Add optional notes
4. Click "Save Debt"

### Generating AI Strategy
1. Click "Generate Strategy" button
2. View personalized repayment recommendations
3. Get cash flow analysis and action items

### Exporting Data
1. Click "Export Data" button
2. Choose between CSV or PDF format
3. Download your financial summary
